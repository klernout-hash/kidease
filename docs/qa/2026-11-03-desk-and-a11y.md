# Desk audit and public-page fixes

Flag `FEATURE_NCF_POINT_DISTANCE` defaults **off**. It does not turn on `FEATURE_NCF_STREET`, `FEATURE_NEED_CARE_FAST`, subscriptions, `SHOW_PAY_CTAS`, in-app purchases, Sponsored, `FEATURE_PROVIDER_SUBSCRIPTIONS`, or `FEATURE_CALL_PUSH`. Huawei ID is not built. `FEATURE_LOGIN_AMAZON` stays off.

## What a parent or daycare will notice

- Dark mode Search and Book a tour text meets WCAG AA. The Live on KidEase chip is a link with `aria-current`, not a pressed button.
- Skip to main content is translated for zh, yue, pa, es, ar, tl, it, and de. Search says Need care fast in the active language when that pack has the line.
- On a video call, mute and camera off change the Twilio track. The other person sees a camera-off or muted note.
- Need care fast keeps today’s city sort until `FEATURE_NCF_POINT_DISTANCE=1`. Then distance uses the listing pin and a postal code or device location. Home daycares use a coarse pin. The page never returns a street address.
- Centre tools show a loading state, then an error with Try again when the load fails. “Tools are off” stays for a centre whose tools are actually off.
- Huawei and Amazon builds hide Google sign-in. The website still hides Google until Google Cloud is turned on.
- `/provider/desk/requests` and `/fr/provider/desk/requests` redirect to the requests desk.
- The daycare message list loads the latest chat line in one query, 50 threads at a time.
- A stale session cookie on a tour or info request is Unauthorized. A guest with no cookie can still send a request.
- The home page does not preload vacancy-index or gov-admin chunks. `/vacancy-index` itself is unchanged.
