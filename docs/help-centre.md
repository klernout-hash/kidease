# Help centre

`FEATURE_HELP_CENTRE` defaults **off**. Set `VITE_FEATURE_HELP_CENTRE=1` for the browser page, because the search box reads the client flag.

`/help` and `/status` stay as they are. `/help/articles` searches short English and French articles and can open a mail draft to support@kidease.ca. Canned replies are added to that draft. Nothing is sent by SMS.

The status page is the public uptime page. This feature does not add a second one.

## GHL

Support mail stays in the KidEase inbox. The CRM bot can file a ticket after the email arrives. Do not put the help search inside GoHighLevel.
