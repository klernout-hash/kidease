# Official languages (EN / FR)

KidEase already stores UI locale in Zustand (`kidease-locale`) and translates chrome through `src/lib/copy.ts`. This document is the **URL** scheme for Canada’s official languages.

## Locale scheme

| Language | URL |
| --- | --- |
| English (default) | unprefixed — `/`, `/privacy`, `/help` |
| French (FR-CA) | `/fr` prefix — `/fr`, `/fr/privacy`, `/fr/help` |

Other header languages (Mandarin, Punjabi, …) do not get path prefixes. Partial packs are not restored as the UI locale.

## Pages with a French URL (v1)

- Home: `/` ↔ `/fr`
- Explore entry: `/search` ↔ `/fr/search` (`/explore` and `/fr/explore` redirect)
- Help / Contact / FAQ / About / Donate to Kids / Start a Daycare
- Get the app / Benefits
- Login (`/login` ↔ `/fr/login`) so the French URL is not a 404
- Privacy, Terms, Cookies
- `/fr/how-it-works` → `/fr#comment`

Desks (`/parent`, `/provider`, `/admin`, `/support`), CF Access `/admin`, and cookie consent stay on their existing English URLs. Switching language there only changes chrome.

## Default and shipped locales

English is the default for a new session and for any unset preference. French sticks only after the user chooses Français (the language control, or a `/fr` URL). Province, IP, and Quebec do not switch the UI.

Shipped chrome is English and French. Mandarin, Punjabi, and the other header packs are partial and are not offered in the language control, so they do not look complete.

## What stays as stored

Daycare and listing names stay as stored. A French registry name stays French when the UI is English. Do not translate proper names. Descriptions and other catalogue / user-provided copy stay English for v1. The French Explore entry says so on the page.

## Language toggle

On a paired marketing or legal page (including `/login`), English ↔ French also changes the URL. On Explore (`/search`) and remaining auth desks the toggle only updates the store so map state and sessions are not reset.

## SEO

Paired pages emit `hreflang` for `en`, `fr`, and `x-default` (English). `public/sitemap.xml` lists the French URLs that actually exist. `/.well-known/security.txt` already prefers `en, fr`.
