# Funding reports

`FEATURE_FUNDING_REPORTS` defaults off. The monthly check compares enrolment counts with attendance days. A mismatch blocks submission. Practice mode logs a clean report and does not submit it. `FEATURE_FUNDING_REPORTS_LIVE=1` marks a clean report ready. KidEase does not file it with the province.

The column layout for every province is a placeholder. Confirm the current claim workbook before anyone submits.

Counts only. No child names. A government user sees totals for `gov_province`.

Pages: `/centre-funding`, `/gov/funding`, `/admin-gov-funding`.
